Count the vowels

Write a loop that counts how many vowels (a, e, i, o, u) are in a word. For "banana", your program should print 3.

# your loop here

5 count += 1

CodeBloom FEEDBACK Not executed

You're close — the loop is right. Line 4 is the only thing to change.

Python reads letter == "a" or "e" as (letter == "a") or "e". A non-empty string like "e" counts as true, so the condition is always true and all 6 letters get counted.
